# FeedFlow

<div align="center">

**FeedFlow** - 让信息流更智能、更优雅。

一个现代化的 RSS 阅读器应用，基于 Nuxt 4 + Element Plus + SQLite + Tauri 构建。

## ✨ 核心功能

### 📰 RSS 订阅管理
- **订阅源管理**：添加、编辑、删除 RSS/Atom 订阅源
- **自动获取元数据**：自动识别订阅源标题、描述、图标等信息
- **分类管理**：支持自定义分类，轻松组织订阅源
- **订阅状态**：实时显示订阅状态和最后更新时间
- **批量操作**：支持批量刷新、批量管理订阅源

### 📖 文章阅读体验
- **三栏布局**：左侧菜单、中间列表、右侧详情，信息层次清晰
- **无限滚动**：流畅的文章列表加载体验
- **文章收藏**：一键收藏重要文章，方便随时回顾
- **全文获取**：支持获取文章完整内容，无需跳转
- **双语显示**：支持原文和译文对照显示，提升阅读体验

### 🤖 AI 智能功能
- **AI 文章总结**：一键生成文章摘要，快速了解核心内容
- **AI 智能翻译**：支持多语言翻译（英语、日语、韩语、法语、德语等 10+ 种语言）
- **智能语言检测**：自动识别文章语言，避免重复翻译
- **翻译偏好设置**：支持双语对照或仅显示译文两种模式
- **结果持久化**：翻译和总结结果自动保存，节省 AI Token 消耗

### 🎨 个性化设置
- **主题切换**：支持浅色、深色、跟随系统三种主题模式
- **字体大小**：可自定义文章阅读字体大小（12-20px）
- **自动刷新**：可设置自动刷新间隔（5-1440 分钟）
- **文章保留**：可设置保留文章数量（100-10000 条）
- **启动刷新**：支持启动时自动刷新订阅源

### 📦 数据管理
- **OPML 导入/导出**：支持从 URL 或文件导入 OPML，轻松迁移订阅源
- **本地存储**：所有数据存储在本地 SQLite 数据库，隐私安全
- **离线阅读**：已下载的文章支持完全离线阅读
- **数据持久化**：文章、翻译、总结结果自动保存，重启应用不丢失

### 🔧 高级功能
- **后台刷新**：支持后台自动刷新，不打扰阅读
- **并发控制**：可设置并发刷新数量，优化性能
- **超时设置**：可配置刷新超时时间，避免长时间等待
- **分类筛选**：支持按分类筛选订阅源和文章

- **主题完善**：完整的深色/浅色主题系统，所有组件完美适配
- **交互流畅**：响应式设计，操作反馈及时
- **布局合理**：三栏布局充分利用屏幕空间，信息展示清晰

### 💡 智能化
- **AI 集成**：内置 AI 总结和翻译功能，提升阅读效率
- **智能缓存**：翻译和总结结果自动缓存，避免重复调用
- **语言检测**：自动识别文章语言，智能判断是否需要翻译

### 🛠️ 可扩展性
- **模块化设计**：代码结构清晰，易于维护和扩展
- **插件系统**：支持 Nuxt 插件系统，方便功能扩展
- **配置灵活**：丰富的设置选项，满足不同用户需求

## 技术栈

- **框架**: Nuxt 4.2.1
- **前端**: Vue 3.5.23
- **UI**: Element Plus 2.11.8
- **数据库**: SQLite (better-sqlite3 12.4.6)
- **语言**: TypeScript 5.9.3
- **桌面应用**: Tauri 2.9.0
- **状态管理**: Pinia 3.0.4
- **RSS 解析**: rss-parser 3.13.0

## 项目结构

```
new_Rss/
├── pages/           # 页面
│   ├── index.vue   # 主布局（包含左侧菜单）
│   ├── articles.vue # 文章列表和详情
│   ├── feeds.vue   # 订阅管理
│   └── settings.vue # 设置
├── stores/          # Pinia 状态管理
│   ├── article.ts  # 文章相关
│   ├── feed.ts     # 订阅相关
│   └── settings.ts # 设置相关
├── composables/     # 组合式函数
│   ├── useDatabase.ts # 数据库操作
│   └── useRss.ts    # RSS 解析
└── plugins/         # Nuxt 插件
    └── pinia.client.ts # Pinia 初始化
```
