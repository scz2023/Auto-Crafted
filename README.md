## 🌟 关于本仓库

**Auto-Crafted** 是一个独特的开源项目集合，致力于展示人工智能在软件开发领域的无限可能。本仓库中的所有项目均由 **AI 完全自主完成**，从架构设计到代码实现，从功能开发到文档编写，每一个细节都体现了 AI 驱动的软件开发新范式。

### 🎯 核心理念

我们相信，AI 不仅是工具，更是创造者。在这个仓库中，每一个项目都是 AI 独立思考、自主设计的产物，它们展现了：

- **🤖 完全 AI 驱动**：所有代码、文档、配置均由 AI 生成，无人工干预
- **🌍 完全开放**：采用公共领域（Public Domain）许可，可自由使用、修改、分发、商业化
- **🚀 生产就绪**：每个项目都经过完整开发，可直接部署使用
- **📚 学习价值**：代码质量高，结构清晰，适合学习和参考

### 📜 许可协议

本项目采用 **公共领域（Public Domain）** 许可，这意味着：

- ✅ **完全免费**：可任意使用，无需付费

## 🚀 项目列表

### [FeedFlow](./FeedFlow/) - 智能 RSS 阅读器

<div align="center">

**FeedFlow** - 让信息流更智能、更优雅

[![Nuxt](https://img.shields.io/badge/Nuxt-4.2.1-00DC82?logo=nuxt.js)](https://nuxt.com)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.9.3-3178C6?logo=typescript)](https://www.typescriptlang.org/)
[![Tauri](https://img.shields.io/badge/Tauri-2.9.0-FFC131?logo=tauri)](https://tauri.app/)

</div>

**FeedFlow** 是本仓库的第一个项目，一个功能完整、设计优雅的现代化 RSS 阅读器应用。

#### ✨ 核心特性

- 📰 **智能订阅管理**：支持 RSS/Atom 订阅源，自动获取元数据，分类管理
- 🤖 **AI 增强功能**：内置 AI 文章总结和智能翻译（支持 10+ 种语言）
- 🎨 **优雅界面**：基于 Element Plus，支持深色/浅色主题
- 📦 **跨平台支持**：基于 Tauri 构建，支持 Windows、macOS、Linux
- 🔒 **隐私优先**：所有数据本地存储，完全离线可用
- ⚡ **高性能**：原生应用性能，启动快速，资源占用低

#### 🛠️ 技术栈

- **前端框架**：Nuxt 4 + Vue 3 + TypeScript
- **UI 组件**：Element Plus
- **桌面框架**：Tauri 2
- **数据存储**：SQLite (better-sqlite3)
- **状态管理**：Pinia
